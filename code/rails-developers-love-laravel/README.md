# Rails to Laravel - Code Examples

This directory contains code examples for the **Rails to Laravel** series.

## Structure

Each chapter has its own directory containing:
- Rails code examples (for comparison)
- Laravel code examples
- Setup instructions
- README with explanations

## Chapters

- `chapter-00/` - Introduction examples
- `chapter-01/` - Concept mapping examples
- `chapter-02/` - Modern PHP examples
- `chapter-03/` - Developer experience examples
- `chapter-04/` - PHP syntax examples
- `chapter-05/` - Eloquent ORM examples
- `chapter-06/` - REST API examples
- `chapter-07/` - Testing and deployment examples
- `chapter-08/` - Ecosystem examples
- `chapter-09/` - Decision framework examples
- `chapter-10/` - Hands-on project

## Requirements

- PHP 8.4+
- Composer
- Laravel 11+
- Ruby 3.x (for comparison examples)
- Rails 7+ (for comparison examples)

## Getting Started

```bash
# Install PHP dependencies
composer install

# For Rails comparison examples
bundle install
```
