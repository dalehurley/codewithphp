# Chapter 01: Mapping Concepts - Rails vs Laravel

This directory contains side-by-side code examples comparing Rails and Laravel concepts.

## Files

- `rails-routing-example.rb` - Rails route definitions
- `laravel-routing-example.php` - Laravel equivalent routes
- `rails-model-example.rb` - ActiveRecord model example
- `laravel-model-example.php` - Eloquent model equivalent
- `quick-reference.md` - Quick lookup reference

## Usage

Compare the Rails and Laravel examples to understand how concepts map between frameworks.

```bash
# Rails example
cat rails-routing-example.rb

# Laravel equivalent
cat laravel-routing-example.php
```

## Key Concepts Covered

1. **Routing** - How Rails routes.rb maps to Laravel routes/web.php
2. **Models** - Rails ActiveRecord vs Laravel Eloquent
3. **Controllers** - Request handling differences
4. **Database** - Migrations and schema definition
5. **Relationships** - associations vs relationships
