KEY FILE PATTERNS
=================

Controllers
-----------
Located in: app/Http/Controllers/
Naming: PascalCase + "Controller" suffix
Example: ContactController.php

Models
------
Located in: app/Models/
Naming: Singular, PascalCase
Example: Contact.php, Company.php
Relationship: One Model per database table

Migrations
----------
Located in: database/migrations/
Naming: Timestamp + descriptive name
Example: 2024_01_15_000001_create_contacts_table.php
Pattern: Creates/modifies database schema

React Components
----------------
Located in: resources/js/Pages/
Naming: PascalCase + .jsx extension
Example: Dashboard.jsx, Contacts/Index.jsx
Pattern: One component per page typically

Routes
------
Located in: routes/
web.php: Traditional web routes
api.php: API endpoints (Sanctum)
channels.php: WebSocket channels (Reverb)

Tests
-----
Located in: tests/
Feature/: Test user-visible functionality
Unit/: Test individual methods
Naming: Test class name matches tested class


IMPORTANT DIRECTORIES YOU'LL MODIFY
===================================

During this series, you'll spend most of your time in:

1. app/Http/Controllers/        - Writing request handlers
2. app/Models/                  - Defining database models and relationships
3. resources/js/Pages/          - Building React components
4. database/migrations/          - Defining database schema
5. routes/                       - Defining application routes
6. resources/views/app.blade.php - Main layout modifications

Less frequently:
- app/Events/                   - When adding real-time features
- app/Jobs/                     - When adding background processing
- config/                       - Configuration changes

BUILD ARTIFACTS (Auto-generated)
==================================

When you run "npm run build", Vite generates:

public/build/
├── manifest.json            - Maps source files to compiled assets
├── app-abc123.js           - Compiled React + JavaScript (versioned)
└── app-def456.css          - Compiled Tailwind CSS (versioned)

These are automatically included in public/views/app.blade.php


ENVIRONMENT-SPECIFIC DIRECTORIES
==================================

Local Development (docker-compose):
- MySQL runs in container
- Redis runs in container
- Files stored in storage/app/
- Logs go to storage/logs/

Production (Laravel Forge):
- MySQL on managed server
- Redis on managed server
- Files stored on S3 or managed file storage
- Logs centralized via monitoring service

The code remains the same; configuration in .env changes per environment.


RUNNING ARTISAN COMMANDS
========================

Throughout the series, you'll use these Artisan commands:

# Generate new files
php artisan make:controller ContactController
php artisan make:model Contact
php artisan make:migration create_contacts_table
php artisan make:job SendEmail

# Database operations
php artisan migrate                    # Run pending migrations
php artisan migrate:rollback           # Undo last migration batch
php artisan migrate:refresh            # Rollback all, then re-migrate

# Development
php artisan serve                      # Start dev server
php artisan tinker                     # Interactive shell

# Queues
php artisan queue:work                 # Process background jobs
php artisan queue:failed               # See failed jobs

# Debugging
php artisan optimize                   # Optimize for production
php artisan route:list                 # See all routes

Access these via: php artisan [command]
Or via Sail: ./vendor/bin/sail artisan [command]


ASSET COMPILATION
=================

Development:
$ npm run dev            # Watch for changes, compile in real-time (HMR)

Production:
$ npm run build          # Minify, optimize, create versioned files

These commands process:
- React JSX → JavaScript
- TypeScript → JavaScript
- Tailwind CSS → Compiled CSS
- Assets → public/build/

Then Inertia automatically loads correct versioned files.
