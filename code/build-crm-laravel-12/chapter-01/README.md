# Chapter 01: Introduction & Series Overview

This directory contains reference materials and tools for Chapter 01 of the **Build a CRM with Laravel 12** series.

## About This Chapter

Chapter 01 is an **introductory and planning chapter** with no actual Laravel code to write yet. Instead, it focuses on:

- Understanding the CRM project scope and features
- Learning about the technology stack
- Exploring the series structure and learning path
- Verifying your development environment is ready

This chapter is essential for setting expectations and understanding the bigger picture before you start coding in Chapter 02.

## Reference Materials

This directory contains helpful reference documents for the entire series:

### 1. `verify-environment.php`

**Purpose**: Verify your development environment is ready for the series.

**What it checks**:
- PHP version (8.4+)
- Required PHP extensions (PDO, MySQL, mbstring, etc.)
- Composer installation
- Node.js version (18+)
- Docker installation (recommended)

**How to run**:

```bash
php verify-environment.php
```

**Expected output**: A colored report showing which tools are installed and their versions.

**When to run**:
- Before starting Chapter 02
- If you get errors during Laravel installation
- To confirm all prerequisites are met

### 2. `TECH-STACK.md`

**Purpose**: Detailed reference for the complete technology stack.

**Contains**:
- Quick reference table of all technologies and versions
- Backend stack explanation (Laravel, Eloquent, Migrations)
- Frontend stack explanation (React, Inertia, Tailwind, shadcn/ui)
- Database and caching layer details (MySQL, Redis)
- Development environment setup (Docker, Sail)
- Official Laravel packages and their purposes
- Version compatibility matrix
- Environment configuration examples
- Performance considerations
- Deployment options

**When to use**: Reference this when you encounter a new technology or want to understand why specific tools were chosen.

### 3. `project-structure.txt`

**Purpose**: Visual reference for the Laravel project directory structure.

**Contains**:
- Complete directory tree with annotations
- Explanation of each major directory
- File naming patterns and conventions
- Database tables added in each chapter
- Build artifact locations
- Artisan command reference

**When to use**:
- When you're unsure where to create a new file
- To understand the overall project organization
- To see what gets generated by `php artisan make:*` commands
- When navigating the project during development

### 4. `series-roadmap.md`

**Purpose**: Complete visual roadmap of all 40 chapters.

**Contains**:
- Seven-part learning path with time estimates
- Detailed chapter breakdown by part
- Technology progression throughout series
- Chapter dependency tree
- Time distribution recommendations
- Per-week learning schedule
- Key milestones showing what's built when
- What you'll accomplish by the end

**When to use**:
- Review at the start to understand the full journey
- Reference during tough chapters to see how they fit in
- Track your progress through the series
- Decide which bonus chapters interest you

## Prerequisites

- PHP 8.4+ installed and working
- Composer installed
- Node.js 18+ installed
- Docker Desktop installed (recommended for Laravel Sail)
- Terminal/command line familiarity

**Verify your setup:**

```bash
php --version        # Should show 8.4 or higher
composer --version   # Should show version 2.0 or higher
node --version       # Should show 18 or higher
docker --version     # Should show Docker is available
```

If any command fails, visit the verification section above or reference `TECH-STACK.md` for installation links.
