# Build a REST API with Laravel 12 for CRM Contacts

Install the [Laravel 12 contact API and queue lab](../api-queue-lab/). The example provides the migration, model, controller, resource and routes for a versioned contacts API.

Follow the [chapter 20 tutorial](https://codewithphp.com/series/build-crm-laravel-12/chapters/20-building-restful-api-crm/) for commands and expected output.
