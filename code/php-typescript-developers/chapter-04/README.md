# Chapter 04: OOP - Classes, Interfaces & Generics

Code examples demonstrating object-oriented programming in PHP.

## Files

- `class-basics.php` - Class syntax, properties, methods, visibility
- `constructor-promotion.php` - Constructor property promotion (PHP 8.0+)
- `interfaces.php` - Interface definitions and implementations
- `abstract-classes.php` - Abstract classes and methods
- `traits.php` - Traits for code reuse
- `inheritance.php` - Class inheritance and method overriding
- `static-members.php` - Static properties and methods
- `magic-methods.php` - PHP magic methods (__get, __set, etc.)
- `generics-phpstan.php` - Generic types with PHPStan annotations
- `practical-repository.php` - Repository pattern implementation

## Running Examples

```bash
cd code/php-typescript-developers/chapter-04

# Run any example
php class-basics.php
php traits.php
php practical-repository.php
```

## Requirements

- PHP 8.0+ (for constructor promotion)
- PHP 8.1+ (for readonly properties)
- PHPStan (optional, for generic type checking)
