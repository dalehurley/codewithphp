# Chapter 03: Functions & Closures - From JS to PHP

Code examples demonstrating PHP functions, closures, and variable capture.

## Files

- `closures-variable-capture.php` - Variable capture with use clause
- `higher-order-functions.php` - Functions returning functions and callbacks
- `generators.php` - Generator functions with yield
- `callable-types.php` - Callable type hints and first-class callables
- `practical-event-emitter.php` - Event emitter implementation
- `functional-programming.php` - Map, filter, reduce, pipe

## Running Examples

```bash
cd code/php-typescript-developers/chapter-03

# Run any example
php closures-variable-capture.php
php generators.php
php practical-event-emitter.php
```

## Requirements

- PHP 8.0+
- PHP 8.1+ (for first-class callable syntax)
