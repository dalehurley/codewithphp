# Chapter 02: Modern PHP Syntax for TS Developers

Code examples demonstrating modern PHP syntax familiar to TypeScript developers.

## Files

- `arrow-functions.php` - Arrow function examples (fn syntax)
- `null-coalescing.php` - Null coalescing and nullsafe operators
- `spread-operator.php` - Spread operator usage
- `match-expression.php` - Match expressions (better than switch)
- `string-interpolation.php` - String interpolation and heredoc
- `named-arguments.php` - Named arguments (PHP 8.0+)
- `property-promotion.php` - Constructor property promotion
- `practical-example.php` - Complete practical example

## Running Examples

```bash
cd code/php-typescript-developers/chapter-02

# Run any example
php arrow-functions.php
php match-expression.php
php practical-example.php
```

## Requirements

- PHP 8.0+ (for named arguments and match)
- PHP 8.1+ (for readonly properties)
