# Chapter 01: TypeScript to PHP - Type Systems Compared

This directory contains code examples comparing TypeScript and PHP type systems.

## Files

- `basic-types.php` - Basic type annotations comparison
- `nullable-union-types.php` - Nullable and union type examples
- `interfaces-classes.php` - Interface and class definitions
- `enums.php` - Enum examples (PHP 8.1+)
- `strict-mode-demo.php` - Strict types demonstration
- `typescript-examples/` - Equivalent TypeScript code for comparison

## Running Examples

```bash
# Navigate to this directory
cd code/php-typescript-developers/chapter-01

# Run any PHP file
php basic-types.php
php nullable-union-types.php
php interfaces-classes.php
php enums.php
php strict-mode-demo.php
```

## Requirements

- PHP 8.3+ (for best feature support)
- PHP 8.1+ minimum (for enums)

## Quick Setup

Verify your PHP version:
```bash
php -v
```

Should show PHP 8.1 or higher.
