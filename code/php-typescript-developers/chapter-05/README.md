# Chapter 05: Error Handling - Try/Catch & Type Safety

Code examples demonstrating PHP exception handling and error management.

## Files

- `basic-try-catch.php` - Basic try/catch/finally usage
- `exception-hierarchy.php` - Exception vs Error classes
- `custom-exceptions.php` - Creating custom exception classes
- `multiple-catch.php` - Handling multiple exception types
- `exception-chaining.php` - Chaining exceptions with context
- `result-type-pattern.php` - Functional error handling with Result type
- `validation-system.php` - Practical validation with exceptions
- `retry-logic.php` - Retry mechanism with exception handling

## Running Examples

```bash
cd code/php-typescript-developers/chapter-05

# Run any example
php basic-try-catch.php
php custom-exceptions.php
php result-type-pattern.php
```

## Requirements

- PHP 8.0+ (for union catch blocks)
- Understanding of exception handling concepts
