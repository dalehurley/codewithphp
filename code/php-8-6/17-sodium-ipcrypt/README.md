# Encrypt IP Addresses with Sodium

Round-trip a documentation IP address through Sodium’s IP encryption functions. Select a mode based on which relationships the stored ciphertext needs to reveal.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/17-sodium-ipcrypt/sodium-ipcrypt.php
```

Requirements: The `sodium` extension with IP encryption support.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/17-sodium-ipcrypt/).
