# Customize Enum Dumps with __debugInfo()

Show a human-readable status and an enum’s machine value when inspecting it with `var_dump()`.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/11-enum-debug-info/enum-debug-info.php
```

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/11-enum-debug-info/).
