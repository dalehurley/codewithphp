# Read and Write ZIP Archives in Memory

Build a tiny archive from generated text and read it back without creating a ZIP file on disk.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/28-zip-in-memory/zip-in-memory.php
```

Requirements: The `zip` extension.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/28-zip-in-memory/).
