# Extend Hash Output with SHAKE and TurboSHAKE

Generate digests at a length chosen by your application. An extendable-output function can produce any requested output length within the API’s limits.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/18-sodium-xof/sodium-xof.php
```

Requirements: The `sodium` extension with SHAKE and TurboSHAKE support.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/18-sodium-xof/).
