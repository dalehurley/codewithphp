# Identify URI and Host Types

Classify URL components for a report. The URI extension exposes distinct methods for the URI form, host form, and whether a WHATWG scheme is special.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/14-uri-types/uri-types.php
```

Requirements: The `uri` extension.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/14-uri-types/).
