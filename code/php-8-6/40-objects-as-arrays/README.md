# Pass Arrays to Array and Compression APIs

Convert a data object at its API boundary. PHP 8.6 deprecates passing objects to array walkers, query building, mbstring conversion, and several compression options.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/40-objects-as-arrays/objects-as-arrays.php
```

Requirements: The `mbstring` and `zlib` extensions.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/40-objects-as-arrays/).
