# Limit Values with clamp()

Keep a page-size setting within an inclusive range. Use the same operation to cap a retry delay represented by a duration.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/05-clamp/clamp.php
```

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/05-clamp/).
