# Change Properties on Objects Held in Constants

Update a mutable object held by a class constant. In PHP 8.6 you can write through the constant expression directly.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/12-constant-object-mutation/constant-object-mutation.php
```

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/12-constant-object-mutation/).
