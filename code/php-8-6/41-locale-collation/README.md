# Replace strcoll() and SORT_LOCALE_STRING with Collator

Sort the same list of names under two locales. PHP 8.6 deprecates `strcoll()` and the `SORT_LOCALE_STRING` flag.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/41-locale-collation/locale-collation.php
```

Requirements: The `intl` extension.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/41-locale-collation/).
