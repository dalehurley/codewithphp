# Audit PHP 8.6 Session Cookie Defaults

Inspect the new defaults for session ID validation and cookie handling. Review your application’s explicit configuration before upgrading.

Run from the repository root with PHP 8.6.

```bash
php -n code/php-8-6/45-session-defaults/session-defaults.php
```

Requirements: The `session` extension. Run this example with `php -n` to see the built-in defaults.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/45-session-defaults/).
