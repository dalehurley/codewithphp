# Build URLs and URI References from Components

Assemble an absolute HTTPS URL and resolve a relative URI reference against a base. The builders give each component its own setter.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/13-uri-builders/uri-builders.php
```

Requirements: The `uri` extension.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/13-uri-builders/).
