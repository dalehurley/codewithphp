# Wait for I/O with Io\Poll

Watch one end of a local socket pair for incoming data. Polling lets a program wait for readiness across many streams with a platform-specific backend.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/03-polling-api/polling-api.php
```

Requirements: A PHP build that supports Unix-domain socket pairs.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/03-polling-api/).
