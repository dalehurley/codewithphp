# Format Localized Number Ranges

Format a temperature range for US English and French. ICU provides locale-specific spacing, punctuation, and units.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/27-intl-number-range/intl-number-range.php
```

Requirements: The `intl` extension with ICU 63 or later.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/27-intl-number-range/).
