# Type-Safe Sorting with SortDirection

Give a leaderboard function a type-safe way to accept a sort direction. Callers choose a case from the built-in enum.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/06-sort-direction/sort-direction.php
```

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/06-sort-direction/).
