# Percent-Encode WHATWG URL Components

Encode a filename as a single path segment and a phrase as form query data. Each component has its own percent-encoding rules.

Run from the repository root with PHP 8.6.

```bash
php code/php-8-6/15-url-percent-encoding/url-percent-encoding.php
```

Requirements: The `uri` extension.

[Read the chapter on Code with PHP](https://codewithphp.com/series/php-8-6/chapters/15-url-percent-encoding/).
