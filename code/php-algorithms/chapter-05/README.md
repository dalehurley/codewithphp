Complete sorting implementations:
- Bubble Sort (basic and optimized)
- Selection Sort
- Cocktail Shaker Sort
- Visualizations
- Performance benchmarks

## Run
```bash
php 01-sorting-algorithms.php
```

## Key Points

- **Bubble Sort**: O(n²) average, O(n) best case with optimization, stable
- **Selection Sort**: O(n²) always, minimal swaps, not stable
- **Both**: Only practical for small arrays (< 100 elements)
- **Production**: Use PHP's built-in `sort()` function
