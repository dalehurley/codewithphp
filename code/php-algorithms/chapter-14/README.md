# Chapter 14: String Search Algorithms - Code Samples

## Files

### 01-naive-kmp-search.php
Naive search and KMP (Knuth-Morris-Pratt) algorithm.

### 02-boyer-moore-rabin-karp.php
Boyer-Moore and Rabin-Karp implementations.

### 03-practical-applications.php
Grep-like search and text highlighting.

## Run
```bash
php 01-naive-kmp-search.php
php 02-boyer-moore-rabin-karp.php
php 03-practical-applications.php
```

## Key Points
- Naive: O(n×m) time complexity
- KMP: O(n+m) time complexity
- Boyer-Moore: Often fastest in practice
- Rabin-Karp: Good for multiple patterns
