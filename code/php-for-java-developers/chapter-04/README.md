# Chapter 4: Classes & Inheritance - Code Examples

This directory contains the code examples from Chapter 4.

## Files

- `Shape.php` - Abstract Shape hierarchy with Circle and Rectangle
- `Employee.php` - Complete employee management system
- `Vehicle.php` - Exercise solution: Vehicle hierarchy
- `Notification.php` - Exercise solution: Notification system
- `PaymentMethod.php` - Polymorphism example

## Running the Examples

```bash
# Run any PHP file
php Shape.php
php Employee.php
php Vehicle.php
php Notification.php
php PaymentMethod.php
```

## Prerequisites

- PHP 8.3 or higher
- Understanding of Java inheritance
