# Chapter 3: OOP Basics - Code Examples

This directory contains the code examples from Chapter 3.

## Files

- `Product.php` - Basic class with properties and methods
- `BankAccount.php` - Encapsulation and visibility example
- `Database.php` - Static members and Singleton pattern
- `MathHelper.php` - Class constants
- `OrderStatus.php` - PHP 8.1 enum example
- `BankAccountExercise.php` - Exercise solution

## Running the Examples

```bash
# Run any PHP file
php Product.php
php BankAccount.php
php Database.php
php OrderStatus.php
php BankAccountExercise.php
```

## Prerequisites

- PHP 8.3 or higher
- Understanding of Java OOP concepts
