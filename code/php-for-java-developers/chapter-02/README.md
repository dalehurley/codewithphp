# Chapter 2: Control Flow & Functions - Code Examples

This directory contains the code examples from Chapter 2.

## Files

- `control-structures.php` - If/else, switch, and match examples
- `loops.php` - For, while, foreach loop examples
- `functions.php` - Function declarations and type hints
- `closures.php` - Anonymous functions and arrow functions
- `Router.php` - Practical router example
- `ArrayUtils.php` - Exercise solution: Array utilities

## Running the Examples

```bash
# Run any PHP file
php control-structures.php
php loops.php
php functions.php
php closures.php
php Router.php
php ArrayUtils.php
```

## Prerequisites

- PHP 8.3 or higher
- Understanding of Java control structures
