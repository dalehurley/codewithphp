# Chapter 0: Setup & First Comparison - Code Examples

This directory contains the code examples from Chapter 0.

## Files

- `hello.php` - Your first PHP script
- `Person.php` - Basic OOP comparison with Java
- `index.php` - Simple web response example
- `Hello.java` - Java equivalent for comparison

## Running the Examples

### PHP Examples

```bash
# Run hello.php
php hello.php

# Run the web server
php -S localhost:8000
# Then visit http://localhost:8000/index.php
```

### Java Examples (for comparison)

```bash
# Compile and run Hello.java
javac Hello.java
java Hello
```

## Prerequisites

- PHP 8.3 or higher
- Java 17+ (for comparison examples)
