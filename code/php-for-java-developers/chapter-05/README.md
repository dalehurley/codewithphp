# Chapter 5: Interfaces & Traits - Code Examples

This directory contains the code examples from Chapter 5.

## Files

- `CacheSystem.php` - Interface + Trait pattern for caching
- `EventSystem.php` - Complete event dispatcher with interfaces and traits
- `Traits.php` - Multiple traits usage examples
- `TraitConflicts.php` - Trait conflict resolution examples

## Running the Examples

```bash
# Run any PHP file
php CacheSystem.php
php EventSystem.php
php Traits.php
php TraitConflicts.php
```

## Prerequisites

- PHP 8.3 or higher
- Understanding of Java interfaces
