# Chapter 1: Types, Variables & Operators - Code Examples

This directory contains the code examples from Chapter 1.

## Files

- `types.php` - PHP type system demonstrations
- `type-juggling.php` - Type juggling examples
- `strict-types.php` - Strict typing demonstrations
- `arrays.php` - Array examples
- `operators.php` - Operator demonstrations
- `Validator.php` - Type-safe validator class
- `TemperatureConverter.php` - Exercise solution

## Running the Examples

```bash
# Run any PHP file
php types.php
php strict-types.php
php Validator.php
```

## Prerequisites

- PHP 8.3 or higher
- Understanding of Java's type system
