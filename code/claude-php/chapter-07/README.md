# Chapter 07: System Prompts and Roles

Master system prompts to define Claude's behavior and expertise.

## 🎯 What You'll Learn

- System prompt design
- Creating personas
- Specialized assistants
- Prompt injection prevention

## 📁 Examples

- `personas.php` - Different AI personas
- `specialized-assistants.php` - Domain-specific assistants
- `prompt-injection-prevention.php` - Security best practices

## 🚀 Quick Start

```bash
composer install
cp .env.example .env
php examples/personas.php
```
