# Chapter 14: Document Processing

Process and extract structured data from various document types using Claude's advanced understanding.

## Examples

1. **pdf-parser.php** - Parse and analyze PDF documents
2. **invoice-extraction.php** - Extract invoice data
3. **contract-analysis.php** - Analyze legal contracts
4. **resume-parser.php** - Parse resumes and CVs

## Supported Documents

- PDF files
- Invoices (PDF, images)
- Contracts and legal documents
- Resumes and CVs
- Forms and applications

## Installation

```bash
composer install
cp .env.example .env
```
