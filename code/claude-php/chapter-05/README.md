# Chapter 05: Prompt Engineering Basics

Master the art of crafting effective prompts for Claude.

## 🎯 What You'll Learn

- Prompt template design
- Few-shot learning techniques
- Chain-of-thought prompting
- Structured output formatting

## 📁 Examples

- `templates.php` - Reusable prompt templates
- `few-shot.php` - Few-shot learning examples
- `chain-of-thought.php` - Step-by-step reasoning

## 🚀 Quick Start

```bash
composer install
cp .env.example .env
php examples/templates.php
```
