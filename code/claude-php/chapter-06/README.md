# Chapter 06: Streaming Responses

Learn to stream Claude responses for real-time user experiences.

## 🎯 What You'll Learn

- Server-Sent Events (SSE)
- Streaming API basics
- Real-time response handling
- Building streaming chatbots

## 📁 Examples

- `streaming-basic.php` - Basic streaming implementation
- `streaming-chatbot.php` - Interactive streaming chatbot
- `sse-handler.php` - Server-Sent Events handler

## 🚀 Quick Start

```bash
composer install
cp .env.example .env
php examples/streaming-basic.php
```
