# Chapter 04: Messages and Conversations

Learn to manage multi-turn conversations and conversation context with Claude.

## 🎯 What You'll Learn

- Multi-turn conversations
- Conversation context management
- Context window management
- Message trimming strategies

## 📁 Examples

- `conversation-manager.php` - Full conversation management class
- `multi-turn.php` - Multi-turn conversation examples
- `context-trimming.php` - Context window management

## 🚀 Quick Start

```bash
composer install
cp .env.example .env
php examples/multi-turn.php
```
