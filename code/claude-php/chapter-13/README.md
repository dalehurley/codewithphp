# Chapter 13: Vision - Working with Images

Claude's vision capabilities allow you to analyze images, extract text (OCR), interpret charts, and moderate visual content.

## Examples

1. **image-upload.php** - Upload and analyze images
2. **ocr.php** - Extract text from images
3. **chart-analysis.php** - Analyze charts and graphs
4. **moderation.php** - Content moderation for images

## Supported Formats

- JPEG, PNG, GIF, WebP
- Base64 encoded or URLs
- Max size: 5MB per image

## Installation

```bash
composer install
cp .env.example .env
```
