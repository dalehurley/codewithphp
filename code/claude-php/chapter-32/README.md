# Chapter 32: Vector Databases

Integrate vector databases (Pinecone, Weaviate) for efficient semantic search and AI-powered applications.

## Installation

```bash
composer install
cp .env.example .env
```

## Examples

- `pinecone-client.php` - Pinecone integration
- `weaviate-client.php` - Weaviate integration
- `hybrid-search.php` - Hybrid search strategies
- `migrations.php` - Vector database migrations
