# Chapter 08: Temperature and Sampling

Control randomness and creativity in Claude's responses.

## 🎯 What You'll Learn

- Understanding temperature parameter
- Sampling strategies (top_p, top_k)
- When to use different temperatures

## 📁 Examples

- `sampling-demo.php` - Sampling parameter demonstration
- `temperature-comparison.php` - Compare different temperatures
- `adaptive-temperature.php` - Dynamic temperature selection

## 🚀 Quick Start

```bash
composer install
cp .env.example .env
php examples/temperature-comparison.php
```
