# Chapter 15: Structured Outputs

Get reliable, validated JSON outputs from Claude using JSON schemas and structured prompting.

## Examples

1. **json-schema.php** - Define and validate JSON schemas
2. **data-validator.php** - Validate extracted data
3. **batch-extraction.php** - Extract data from multiple sources
4. **streaming-json.php** - Stream structured JSON responses

## Features

- JSON Schema validation
- Type-safe outputs
- Batch processing
- Streaming support

## Installation

```bash
composer install
cp .env.example .env
```
