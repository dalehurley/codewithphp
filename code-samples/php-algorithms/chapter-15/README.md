# Chapter 15: Arrays & Dynamic Arrays - Code Samples

## Files

### 01-dynamic-array.php
Complete dynamic array implementation with automatic resizing and shrinking.

### 02-array-patterns.php
Common algorithms: Two pointers, sliding window, prefix sum, Kadane's algorithm.

### 03-circular-buffer.php
Fixed-size circular buffer (ring buffer) implementation.

## Run
```bash
php 01-dynamic-array.php
php 02-array-patterns.php
php 03-circular-buffer.php
```

## Key Concepts
- Dynamic arrays resize automatically
- Amortized O(1) append operation
- Resize strategy: double when full, halve when 1/4 full
- Common patterns optimize array operations
- Circular buffers efficient for fixed-size queues
