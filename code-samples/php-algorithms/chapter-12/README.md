# Chapter 12: Binary Search - Code Samples

Comprehensive PHP code samples for Binary Search algorithms.

## Files

### 01-basic-binary-search.php
- Iterative and recursive implementations
- Visualized search process
- Performance comparisons

### 02-binary-search-variants.php
- Find first/last occurrence
- Find insertion position
- Count occurrences

### 03-advanced-applications.php
- Integer square root
- Peak element finding
- Answer space search

## Requirements
- PHP 8.0+
- Sorted arrays required for all examples

## Run All
```bash
php 01-basic-binary-search.php
php 02-binary-search-variants.php
php 03-advanced-applications.php
```
