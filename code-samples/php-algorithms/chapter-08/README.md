# Chapter 08: Heap Sort & Priority Queues

Complete heap sort implementation and priority queue data structure.

## Code Files

### 01-heap-sort.php
Heap sort algorithm with visualization and performance analysis.

**Run:** `php 01-heap-sort.php`

### 02-priority-queue.php
Max heap-based priority queue for task scheduling and prioritization.

**Run:** `php 02-priority-queue.php`

## Key Concepts

- **Heap Sort:** O(n log n) guaranteed, O(1) space, not stable
- **Priority Queue:** O(log n) insert/extract, O(1) peek
- **Applications:** Job scheduling, event simulation, shortest path algorithms
