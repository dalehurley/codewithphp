# Chapter 01: Algorithm Complexity & Big O - Code Samples

Learn to analyze algorithm efficiency using Big O notation with practical PHP examples.

## Files in This Chapter

### 1. `01-complexity-examples.php`
Demonstrates all major time complexity classes with working code

### 2. `02-space-complexity.php`
Shows memory usage patterns and space complexity analysis

## Quick Reference

| Complexity | Name | Example Operations | Max Practical Size |
|------------|------|-------------------|-------------------|
| O(1) | Constant | Array access, hash lookup | Unlimited |
| O(log n) | Logarithmic | Binary search | Billions |
| O(n) | Linear | Array traversal | 100M+ |
| O(n log n) | Linearithmic | Merge sort, quick sort | 10M+ |
| O(n²) | Quadratic | Bubble sort, nested loops | 10K |
| O(2^n) | Exponential | Naive Fibonacci | ~25 |
| O(n!) | Factorial | Permutations | ~12 |

## Run the Examples

```bash
php 01-complexity-examples.php
php 02-space-complexity.php
```
