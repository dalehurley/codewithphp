## New to programming

Start with [Write and Run Your First PHP Script](/series/php-basics/chapters/01-your-first-php-script/). Open its browser example, change the greeting, and run it again. You’ve written your first PHP instruction when the output shows your new greeting.

To try it on your machine, [install PHP](/series/php-basics/chapters/00-setting-up-your-development-environment/) and repeat the exercise in your terminal. When you’re ready for a small project, follow the [PHP and SQLite reading list starter](/series/php-basics/sqlite-starter/).

If you already build static pages, try [PHP for HTML and CSS developers](/learn/php-for-html-css/). There is also [a first PHP script in Spanish](/learn/primer-script-php/).

## Switching from another language

Choose a lesson for a language you know. Pick one side-by-side example, run the PHP version, and change an input to see how it behaves. If you need PHP on your machine, start with the [setup instructions](/series/php-basics/chapters/00-setting-up-your-development-environment/).

| You know | Start with |
| --- | --- |
| JavaScript or TypeScript | [Compare the PHP and TypeScript type systems](/series/php-typescript-developers/chapters/01-type-systems-compared/) |
| Python | [Translate familiar Python syntax into PHP](/series/python-developers-love-php-laravel/chapters/04-php-syntax-language-differences-for-python-devs/) |
| Ruby or Rails | [Compare Ruby and PHP syntax](/series/rails-developers-love-laravel/chapters/04-php-syntax-for-rails-devs/) |

| Another language | [Call a function with a parameter and use its return value](/series/php-basics/chapters/04-understanding-and-using-functions/) |

## Returning to PHP

Try [Can PHP Be Typed?](/series/php-misconceptions/chapters/01-php-types/). Run the example that passes a numeric string to a typed function, then compare the default and strict results. It’s a short way to see what modern PHP enforces at runtime.

If you’re picking up an existing project, run `php -v` in the shell or container where that project runs. Use the [PHP 8.5 to 8.6 upgrade checklist](/series/php-8-6/upgrade-checklist/) if that’s your next upgrade.

For more practice, try the [seven-day PHP starter plan](/learn/seven-day-php-plan/) or explore the [PHP resource library](/resources/). If you already know what you want to build, [browse all PHP courses](/series/).
