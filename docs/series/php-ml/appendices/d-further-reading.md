## Books

### Machine Learning Fundamentals
- **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow"** by Aurélien Géron
  - Practical approach with Python (concepts apply to PHP-ML)
  - Clear explanations with code examples
  - Covers fundamentals to deep learning

- **"An Introduction to Statistical Learning"** by James, Witten, Hastie, Tibshirani
  - Free online: [statlearning.com](https://www.statlearning.com/)
  - Statistical foundation for ML
  - Examples in R (concepts transfer to PHP)

- **"The Hundred-Page Machine Learning Book"** by Andriy Burkov
  - Concise ML overview
  - Covers key algorithms
  - Great for quick reference

### Mathematics for ML
- **"Mathematics for Machine Learning"** by Deisenroth, Faisal, Ong
  - Free online: [mml-book.github.io](https://mml-book.github.io/)
  - Linear algebra, calculus, probability
  - Tailored for ML applications

## Online Courses

### Free Courses
- **[Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)** by Google
  - Free, self-paced
  - 15 hours of video lectures
  - Interactive exercises

- **[Fast.ai Practical Deep Learning](https://course.fast.ai/)**
  - Free, top-down approach
  - Start coding immediately
  - Theory comes from practice

- **[Kaggle Learn](https://www.kaggle.com/learn)**
  - Free micro-courses
  - Hands-on exercises
  - Covers Python scikit-learn (similar to PHP-ML)

### Paid Courses
- **[Andrew Ng's Machine Learning](https://www.coursera.org/learn/machine-learning)** on Coursera
  - Classic ML course
  - Mathematical foundations
  - Certificate available

- **[DeepLearning.AI Specialization](https://www.deeplearning.ai/)**
  - Comprehensive deep learning
  - From basics to advanced
