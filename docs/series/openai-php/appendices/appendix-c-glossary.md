# Appendix C: Glossary

Comprehensive definitions of AI, OpenAI, and technical terms used in this series.

## A

**API (Application Programming Interface)**
Interface that allows different software applications to communicate with each other.

**API Key**
Secret authentication token used to access OpenAI's APIs securely.

**Assistants API**
OpenAI's stateful API for building AI assistants with persistent threads and built-in tools.

**Async/Asynchronous**
Programming pattern where operations don't block execution, allowing concurrent processing.

---

## B

**Backoff (Exponential)**
Retry strategy that increases wait time between attempts exponentially (e.g., 1s, 2s, 4s, 8s).

**Batch Processing**
Processing multiple items together in a single operation for efficiency.

**Beam Search**
Decoding algorithm that explores multiple possible sequences to find the most likely output.

---

## C

**Caching**
Storing frequently accessed data in fast-access memory to reduce API calls and improve performance.

**Chain-of-Thought (CoT)**
Prompting technique where the model is asked to show its reasoning step-by-step.

**Chat Completions API**
OpenAI's primary API for conversational AI interactions using GPT models.

**Chunk/Chunking**
Breaking large documents into smaller segments for processing or embedding.

**Code Interpreter**
Assistants API tool that allows AI to write and execute Python code for data analysis.

**Completion**
The output generated by an AI model in response to a prompt.

**Context Window**
Maximum number of tokens (input + output) a model can process in a single request.

**Cosine Similarity**
Measure of similarity between two vectors based on the cosine of the angle between them.

---

## D

**Deterministic**
Producing the same output for the same input (achieved with temperature=0).

**Dependency Injection**
Design pattern where dependencies are provided to a class rather than created internally.

**Dotenv**
PHP library for loading environment variables from `.env` files.

---

## E

**Embedding**
Numerical vector representation of text that captures semantic meaning.

**Endpoint**
Specific URL in an API that performs a particular function.

**Euclidean Distance**
Straight-line distance between two points in vector space.

---

## F

**Few-Shot Learning**
Providing a few examples in the prompt to guide the model's behavior.

**Fine-Tuning**
Training a pre-trained model on custom data to specialize it for specific tasks.

**Finish Reason**
Indicator of why model generation stopped (e.g., "stop", "length", "content_filter").

**Frequency Penalty**
Parameter that reduces repetition by penalizing tokens based on their frequency in the text.

**Function Calling**
Feature allowing models to call predefined PHP functions based on user input.

---

## G

**Generator (PHP)**
Function that yields values one at a time instead of building an array in memory.

**GPT (Generative Pre-trained Transformer)**
Type of large language model architecture used by OpenAI.

**Guzzle**
Popular PHP HTTP client library used for making API requests.

---

## H

**Hallucination**
When AI generates plausible-sounding but incorrect or nonsensical information.

**HTTP Client**
Software component that makes HTTP requests to APIs.

---

## I

**Injection (Prompt Injection)**
Security vulnerability where users manipulate prompts to make the AI behave unexpectedly.

**Instruction Tuning**
Training technique where models learn to follow natural language instructions.

---

## J

**JSON Mode**
Feature that ensures model outputs valid JSON that matches a specified schema.

---

## K

**K-Nearest Neighbors (KNN)**
Algorithm for finding k most similar items based on vector distance.

---

## L

**Large Language Model (LLM)**
AI model trained on vast amounts of text data to understand and generate human language.

**Latency**
Time delay between sending a request and receiving a response.

**Logit**
Raw prediction score before being converted to a probability.

**Logit Bias**
Parameter to adjust the likelihood of specific tokens appearing in outputs.

---

## M

**Max Tokens**
Maximum number of tokens the model should generate in a response.

**Message**
Single unit of conversation containing a role (system/user/assistant) and content.

**Middleware**
Software layer that processes requests/responses between client and server.

**Multi-Modal**
AI capable of processing multiple types of input (text, images, etc.).

---

## N

**Nucleus Sampling (Top-P)**
Sampling strategy that considers tokens whose cumulative probability exceeds threshold p.

---

## O

**One-Shot Learning**
Providing one example in the prompt to guide the model's behavior.

**OPcache**
PHP extension that improves performance by caching precompiled script bytecode.

---

## P

**Parallel Processing**
Executing multiple operations simultaneously for improved performance.

**PII (Personally Identifiable Information)**
Data that can identify a specific individual (names, emails, addresses, etc.).

**Presence Penalty**
Parameter that encourages model to talk about new topics.

**Prompt**
Input text provided to an AI model to generate a response.

**Prompt Engineering**
Craft of designing effective prompts to get desired outputs from AI models.

---

## Q

**Queue**
System for managing background jobs to be processed asynchronously.

---

## R

**RAG (Retrieval-Augmented Generation)**
Technique combining information retrieval with generation for factual responses.

**Rate Limit**
Maximum number of requests allowed within a time period.

**Redis**
In-memory data store used for caching and session management.

**Retry Logic**
Automatic re-attempt of failed operations with configurable delays.

**Role**
Identifier for who is speaking in a conversation (system, user, assistant, function, tool).

**RPM (Requests Per Minute)**
Rate limit measure for number of API requests allowed per minute.

---

## S

**Sampling**
Process of selecting the next token during text generation.

**SDK (Software Development Kit)**
Collection of tools, libraries, and documentation for developing with a platform.

**Seed**
Number used to initialize random number generation for deterministic sampling.

**Semantic Search**
Search that understands meaning and context, not just keyword matching.

**Server-Sent Events (SSE)**
Standard allowing servers to push data to clients over HTTP.

**Similarity Search**
Finding items most similar to a query based on vector distance.

**Stop Sequence**
Token or string that tells the model to stop generating.

**Stream/Streaming**
Sending response data incrementally as it's generated rather than all at once.

**System Prompt**
Initial message that sets the behavior and personality of the AI assistant.

---

## T

**Temperature**
Parameter controlling randomness in model outputs (0=deterministic, 2=maximum creativity).

**Throttling**
Controlling the rate of requests to stay within limits.

**Token**
Basic unit of text processing (~4 characters or ¾ of a word in English).

**Tool**
Function or capability that an AI assistant can use (e.g., web search, calculator).

**Top-K Sampling**
Sampling strategy that considers only the k most likely next tokens.

**Top-P Sampling**
See Nucleus Sampling.

**TPM (Tokens Per Minute)**
Rate limit measure for number of tokens that can be processed per minute.

**Transformer**
Neural network architecture that powers modern language models.

---

## U

**Union Types**
PHP 8.0+ feature allowing a variable to accept multiple types.

---

## V

**Vector**
Array of numbers representing text or other data in mathematical space.

**Vector Database**
Database optimized for storing and searching high-dimensional vectors.

**Vector Store**
Component of Assistants API for storing and retrieving documents.

---

## W

**Webhook**
HTTP callback that notifies your application when an event occurs.

---

## Z

**Zero-Shot Learning**
Having the model perform a task without providing any examples in the prompt.

## PHP-Specific Terms

**Composer**
Dependency manager for PHP.

**PSR (PHP Standard Recommendation)**
Community-driven PHP coding standards.

**Attribute**
PHP 8.0+ feature for adding metadata to code declarations.

**Trait**
Mechanism for code reuse in PHP's single inheritance language.

**Namespace**
Way to encapsulate items to avoid name collisions.
